# Ember Atlas — Dragon Village 3 Field Guide

A lightweight responsive fan-made guide for Dragon Village 3. Built with plain HTML, CSS, and JavaScript for direct GitHub Pages hosting.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Publish

A GitHub Actions workflow deploys the site when changes are pushed to `main`. In repository **Settings → Pages**, select **GitHub Actions** as the build source if it is not set automatically. The address will be `https://<your-github-name>.github.io/<repository-name>/`.

The dragon index is a starter collection aid, not a complete official roster or a source of exact stats, rates, or breeding combinations. Confirm current game values in-game.
